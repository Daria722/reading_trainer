# Reading Trainer

**Веб-система тестирования и оценки эффективности восприятия текстовой информации.**

Курсовой проект по специальности «Прикладная математика».

## О проекте

Приложение позволяет пользователю выбрать текст, прочитать его с фиксацией фактического времени (срабатывает таймер и механизм скрытия текста), после чего пройти тестирование на основе случайно выбранных вопросов из банка данных.

Система автоматически рассчитывает:
- **Скорость чтения ($V$ / WPM)** — количество слов в минуту с учетом норматива объема текста.
- **Качество понимания ($Q$)** — процент правильных ответов на контрольные вопросы.
- **Комплексный показатель эффективности ($E = V \times Q$)**.
- Сравнение фактического времени чтения с расчетным нормативом.

## Стек технологий

- **Язык:** Python
- **Бэкенд:** Django, PostgreSQL
- **Фронтенд:** HTML5, CSS3 (Bootstrap 5), JavaScript
- **Среда разработки:** Visual Studio Code

## Структура проекта

- `backend/` — серверная логика (Django-проект `config` и приложение `core`).
- `frontend/` — шаблоны HTML (`templates/`) и статические файлы (`static/css`, `static/js`).
- `media/` — загружаемые файлы.
- `docs/` — документация (ER-диаграмма базы данных, блок-схема алгоритма).
